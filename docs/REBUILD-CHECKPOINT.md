# Native rebuild checkpoint

September 7, 2026: native desktop workflow coverage and Chromium interaction testing are implemented. See `NATIVE-REBUILD.md` for the full capability inventory, verification evidence, practical limits and later research features. `NATIVE-BROWSER-QA.md` records the actual browser checks and repeatable scripts.

The main route uses React/TypeScript with a browser geometry worker. `/classic` preserves the prior Java migration. Old `.tap` compatibility is intentionally excluded by the user's instruction.

The zoom-dependent interlace flip is fixed through viewport-independent weave choices. Polygonal band joints and angled underpasses replace the early round background masks. The original 92 tilings and 73 examples, French controls, inner/outer fills, shadows, raster/EPS outputs and construction-copy workflows are available natively.

The development server is at `http://localhost:3000/` while the machine is running. Source and downloaded project files survive closing the computer; restart with `npm run dev` if necessary. Browser autosaves and the privately published app have separate origin-local storage. Download a `.taprats.json` file to transfer a document between them.

Later features include true substitution tilings, cut-piece fabrication analysis, strand coloring, reusable motif libraries, recovery snapshots and perspective rectification. These are not claimed complete by this checkpoint.
